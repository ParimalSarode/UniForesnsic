# Changelog

## v0.1.0 (2026-03-01)

### 🎉 Initial Release

- **Core Loop Engine** — Iterative AI agent execution with file-based memory
- **Sidebar UI** — Activity bar panel with live session status and configuration
- **Status Bar** — Real-time loop state, iteration counter, and elapsed timer
- **Auto-Completion** — Unique per-session markers for automatic loop termination
- **Backpressure Validation** — Configurable test/lint/build/package checks after each iteration
- **Git Integration** — Auto-commit after iterations, optional branch-per-session
- **Dynamic Model Registry** — Bundled model list with optional remote URL fetch
- **Antigravity API Client** — Port auto-discovery, CSRF/OAuth token management
- **Output Channel** — Debug logging with iteration boundary markers
- **14 Commands** — Start, stop, pause, emergency stop, file selection, configuration
